Privacy

VoRoute is operated by Ayush Mishra. It is in development. This site does not take orders, and it does not place calls.

This website

voroute.com is a static page. There is no account, no form, and no analytics. Opening it does not create a customer record.

When a confirmation call exists

A store will send an order so VoRoute can confirm it before dispatch. That record is limited to what the call needs:

  • Order id, customer name, phone number, amount, and whether the order is cash on delivery.
  • The confirmation script, call attempts, and the result: confirmed, cancelled, address fix, or no answer.

The phone number is the one the customer gave the store at checkout. It is used to place that order’s confirmation call, not to build a marketing list.

Who it is shared with

To place a call, the number and the script have to reach the telephony provider and the voice services that listen and speak. Those providers process the call. VoRoute does not sell personal data.

How long it is kept

The result is kept with the order so the store can ship or hold. It is not kept as a separate contact database.
