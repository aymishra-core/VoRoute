Privacy

VoRoute is operated by Ayush Mishra. This page says what a confirmation uses. It does not set a retention period.

This website

voroute.com is a set of static pages. It does not ask for an order, a phone number, or a password.

An order a store sends

A store can send a cash-on-delivery order so VoRoute can call the customer. The record is the order id, the customer’s name, the phone number, the amount, and that the order is cash on delivery. The call’s result is stored with that order: confirmed, declined, or unclear. The words the customer said may be stored with the result.

The phone number is the one from that order. It is used to place that order’s confirmation call.

Who hears the call

Placing the call means the number and the spoken line go to the phone provider, and the customer’s voice goes to the speech service that turns it into text. The store that sent the order can see the result.
