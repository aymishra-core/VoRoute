VoRoute is the production server-side voice AI that places outbound calls to confirm cash-on-delivery orders in Hinglish and cut return-to-origin for Indian D2C brands; LAI remains the showpiece and the source of the voice engine that will be ported into `vocore` later. From the repo root, create a virtualenv, install with `pip install -e ".[dev]"`, copy `.env.example` to `.env` when you have keys, then run `uvicorn voroute.main:app --reload`.
